# Changelog

## Unreleased

- Added optional semantic scene decomposition with cached per-scene depth and object masks.
- Added open-vocabulary multi-entity detection through Grounding DINO with deterministic classical fallback.
- Added multi-object SAM 2 tracking with optical-flow fallback, preserving per-entity labels, roles, confidence, area, centroid, and motion metadata.
- Added entity-aware compositor targeting by entity ID, role, or label.
- Added subject isolation, subject echo, depth parallax, entity fragmentation/split, tracked contour glow, and semantic mask-transition materialization primitives.
- Added a deterministic music-aware semantic director that uses energy, bass, percussion, build/drop state, entity motion, and entity count to select sparse treatments.
- Added `tubeviz-semantic` indexing, inspection, materialization, and timeline semanticization commands. Semantic treatments are materialized before normal Tubeviz rendering so browser/native renderers do not require ML runtimes.
